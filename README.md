# Интерактивный BI-дашборд анализа коммерческой эффективности e-com платформы

![Интерактивный дашборд](Анализ ком.эффективности Caravan.png)

## 🎯 Описание бизнес-кейса
Проект посвящен автоматизации сбора данных, очистке и визуализации ключевых метрик коммерческого департамента e-commerce платформы за осенний период 2025 года. Цель проекта — предоставить топ-менеджменту инструмент для ad-hoc анализа региональной эффективности, выполнения планов продаж менеджерами и структуры товарного ассортимента.

## 🛠️ Технологический стек и навыки
* **Power Query (ETL):** Импорт данных из нескольких разноформатных источников (CSV, XLSX), устранение текстовых аномалий, очистка невидимых пробелов (Trim), извлечение данных по разделителям, приведение типов данных (включая работу с локалью для некорректных форматов дат и защиту ИНН от числового искажения), фильтрация системного мусора (строк «Итого»).
* **Моделирование данных:** Построение классической схемы «Звезда» (Star Schema) с однонаправленными связями (один-ко-многим) от справочников к таблицам фактов транзакций.
* **DAX (Аналитические вычисления):** Разработка динамических мер с контролем контекста фильтрации, безопасное деление (`DIVIDE`), агрегатные функции, подсчет уникальных значений (`DISTINCTCOUNT`).
* **Data Visualization & UX/UI:** Проектирование интерактивного интерфейса с использованием срезов, комбинированных диаграмм и кастомной логики KPI-карточек.

## 📊 Ключевые метрики, реализованные в модели
1. **Общая выручка (Revenue):** Суммарный объем успешных продаж компании.
2. **Средний чек (AOV):** Рассчитывается динамически как отношение выручки к общему количеству уникальных транзакций (строк лога) через `COUNTROWS`.
3. **Выполнение KPI (%):** Динамическое сопоставление фактической выручки с плановыми показателями задействованных менеджеров.
4. **Уникальный ассортимент & Клиентская база:** Расчет активных клиентов и уникальных товарных позиций в обороте (`DISTINCTCOUNT`).
5. **Доля категорий в штуках продаж:** Структурный анализ ходового ассортимента на пончиковой диаграмме.

## 📝 Примеры формул DAX, написанных в проекте
* **Безопасный расчет выполнения плана:**
  ```dax
  Выполнение KPI = DIVIDE([Выручка], SUM('План продаж для менеджеров'[План продаж]), 0)
  ```
* **Динамический расчет среднего чека (AOV):**
  ```dax
  Средний Чек = DIVIDE([Выручка], COUNTROWS('Данные'), 0)
  ```

## 📈 Результаты для бизнеса
Дашборд позволяет коммерческому директору в один клик менять контекст анализа (выбирать конкретный город или категорию товаров) и мгновенно видеть:
* Рейтинг менеджеров по вкладу в общую выручку;
* Сезонные тренды и пики продаж на линейном графике по дням;
* Доли категорий товаров, формирующих основной объем отгрузок.
